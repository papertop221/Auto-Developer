# Contributing to Auto-Developer

Thank you for your interest in improving Auto-Developer! We welcome contributions from everyone.

## How to Contribute

1.  **Report Bugs**: Open an issue describing the bug and how to reproduce it.
2.  **Suggest Features**: Open an issue with a clear description of the proposed feature.
3.  **Submit Pull Requests**:
    *   Fork the repository.
    *   Create a new branch for your changes.
    *   Ensure your code follows the project's style.
    *   Write or update tests as necessary.
    *   Submit a PR with a clear description of your changes.

## Code of Conduct

Please be respectful and professional in all interactions.

## Technical Standards

This project follows a strict 7-phase SDLC. Please refer to the `references/` directory for detailed specifications on our development process.
