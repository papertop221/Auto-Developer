# Phase 4: Surgical Implementation

Implement the design using an iterative, verification-driven approach.

## 1. Plan-Act-Validate Loop
For every module:
1. **Plan**: Describe the implementation steps.
2. **Act**: Write the code surgically. Avoid unrelated changes.
3. **Validate**: Run tests immediately to confirm behavioral correctness.

## 2. Implementation Standards
- Use idiomatic code patterns for the chosen language.
- Include clear, technical comments (no jargon).
- Handle all edge cases and error conditions locally.
- Never use placeholders or "TODO" in "complete" files.

## 3. Continuous Integration (Manual)
- After every logical unit, run all existing tests to ensure no regressions.
- Update `PROJECT_STATE.md` with task completion status.
