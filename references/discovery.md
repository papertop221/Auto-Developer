# Phase 1: Discovery & Context Mapping

This phase focuses on understanding the user's intent and the operational environment.

## 1. Requirement Gathering
- Use `ask_user` to clarify ambiguous terms.
- Identify core functional requirements (what it does).
- Identify non-functional requirements (performance, security, portability).
- Define "Out of Scope" items to prevent feature creep.

## 2. Environment Analysis
- Check available runtimes (Python, Node.js, Go, etc.).
- Identify system constraints (Termux file permissions, no GUI, ARM architecture).
- Verify internet connectivity if the app requires external APIs.

## 3. Success Criteria
- Define measurable metrics for project completion.
- Create a `REQUIREMENTS.md` file in the project root to serve as the single source of truth.
