# User Language & Error Translation Guide

This guide ensures the Auto-Developer communicates with the user in plain, non-technical language (Indonesian and English).

## Error Translation Table

| Technical Error | Plain Indonesian | Plain English |
|-----------------|------------------|---------------|
| `FileNotFoundError` | "File yang dibutuhkan tidak ditemukan." | "A required file is missing." |
| `ModuleNotFoundError` | "Ada komponen yang belum terpasang, sedang memasang..." | "Some components are missing, installing them now..." |
| `SyntaxError` | "Ada kesalahan penulisan kode, sedang memperbaiki..." | "Found a typo in the code, fixing it now..." |
| `ConnectionError` | "Tidak bisa terhubung ke internet." | "Cannot connect to the internet." |
| `PermissionError` | "Tidak ada izin untuk mengakses file ini." | "Permission denied for this file." |
| `KeyboardInterrupt` | "Program dihentikan oleh pengguna." | "Program stopped by user." |
| `ZeroDivisionError` | "Kesalahan perhitungan matematika (bagi nol)." | "Mathematical calculation error." |
| `TypeError` | "Format data tidak sesuai." | "Incorrect data format." |
| `IndexError` | "Data yang dicari tidak ada dalam daftar." | "Requested item not found in list." |
| `sqlite3.Error` | "Ada masalah dengan penyimpanan data (database)." | "There is a problem with the data storage." |

## Phrases for Progress

| Phase | Indonesian Phrase | English Phrase |
|-------|-------------------|----------------|
| Planning | "📋 Sedang merancang struktur program..." | "📋 Designing the program structure..." |
| Coding | "🔧 Sedang menulis kode..." | "🔧 Writing code..." |
| Installing | "📦 Sedang memasang paket tambahan..." | "📦 Installing additional packages..." |
| Testing | "🧪 Sedang menguji fungsionalitas..." | "🧪 Testing functionality..." |
| Fixing | "🔄 Menemukan kendala, sedang mencoba memperbaiki otomatis..." | "🔄 Encountered an issue, attempting automatic fix..." |
| Success | "✅ Selesai! Program siap digunakan." | "✅ Done! The program is ready to use." |
