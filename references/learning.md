# Phase 7: Post-Mortem & Knowledge Consolidation

Learn from every project to improve future performance.

## 1. Retrospective Analysis
- Review the `PROJECT_STATE.md` and `RESEARCH_LOG.md`.
- Identify what went well and what caused delays or errors.

## 2. Pattern Extraction
- Extract reusable utility functions or architectural patterns.
- Record "Anti-Patterns" to avoid in the future.

## 3. Skill Evolution
- Propose updates to the `auto-developer` skill based on project data.
- Update global personal memory with newly acquired technical facts.
